# Arhiva — Android (probna)

Android omotač (Capacitor 8.5.2) oko web Arhive. Probna verzija učitava Arhivu sa
https://arhiva-app.github.io/arhiva/ — izmene u Arhivi stižu ponovnim otvaranjem aplikacije.
Nov APK treba samo kad se menja Android deo (dodaci, dozvole, ikonica).

Most ka telefonu (`cap/capacitor.js`, `cap/arhiva-native.js`) je u web Arhivi i učitava se samo u ovoj aplikaciji.

Najnoviji APK: https://github.com/arhiva-app/arhiva-android/releases/latest/download/Arhiva-probna.apk
