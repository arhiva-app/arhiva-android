# Arhiva — Android (probna)

Android omotač (Capacitor) oko web Arhive (`arhiva-app/arhiva`). Kod Arhive se ne kopira ovde:
GitHub Actions pri svakom pravljenju uzme objavljenu web Arhivu, doda `native/arhiva-native.js`
(preuzimanje → Documents/Arhiva, deljenje → Android „Podeli“) i napravi APK.

Najnoviji APK: https://github.com/arhiva-app/arhiva-android/releases/latest/download/Arhiva-probna.apk
